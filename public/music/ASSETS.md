# Vesper soundtrack

Five original tracks supplied by the project owner from `Games/VESPER_MUSIQUE` on 14 September 2026. The game copies are encoded as 160 kbps MP3 for streaming. The original masters remain untouched.

- `lumiere.mp3` — Tant qu'une lumière demeure
- `derniere-charge.mp3` — La Dernière Charge
- `cloches.mp3` — Les Cloches des Damnés
- `ce-qui-reste.mp3` — Ce qui nous reste
- `chair-acier.mp3` — Chair et Acier

Only the selected song is loaded. Each run selects a different random track unless a specific song is chosen in Settings.
